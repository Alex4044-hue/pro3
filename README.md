# Spring Boot gRPC Template Project
Clone the Spring Boot Maven project (template) from the Git repository or download the project. This is Maven configured and thus has all the needed dependencies and plugins.
## From the command line:
$git clone [https://github.com/viajook/spring-boot-grpc-server-example.git](https://github.com/viajook/spring-boot-grpc-server-example.git)

Open the project in IntelliJ and “Load Maven Changes” 

N/B: Remember to add the 'generated' folder which contains the generated codes to .gitignore
